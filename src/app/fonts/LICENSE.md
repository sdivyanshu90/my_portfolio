# Fonts

Self-hosted so builds and the dev server never depend on Google Fonts.

- **Newsreader** (roman, italic; variable 200–800) — Production Type, SIL Open Font License 1.1
- **IBM Plex Mono** (400, 500, 600) — IBM, SIL Open Font License 1.1

Latin subsets as served by Google Fonts. `newsreader-500.ttf` is used by
`next/og` for share images (it needs TrueType, not WOFF2).
